**INTERACTIVE IMAGE PROCESSING & KERNEL VISUALIZER**
An interactive web-based Image Processing Visualizer for understanding spatial-domain operations, convolution kernels, pixel values, gradient operators, and step-by-step image processing calculations.

**🌐Live Demo:** https://rukmani0920.github.io/Interactive-Image-Processing-Kernel-Visualizer/

**Features**
* Interactive image upload and visualization
* Original image with adjustable viewing size
* Real-time processed image output
* Dynamic 3 × 3 kernel visualization
* Step-by-step kernel convolution calculation
* Interactive pixel and 3 × 3 region selection
* RGB and grayscale pixel inspection
* Complete image pixel-value visualization
* Pixel × Kernel calculation display
* Spatial-domain image filtering
* Blur and sharpening operations
* Sobel X and Sobel Y operators
* Prewitt X and Prewitt Y operators
* Laplacian and edge-detection operations
* Operation-specific theory and formulas
* Original and processed image comparison

**Concepts Demonstrated**
* Spatial Domain Processing
* Image Filtering
* Image Kernels
* Convolution
* Pixel-Level Image Processing
* Grayscale Conversion
* Gradient Operators
* Edge Detection
* Sobel Operator
* Prewitt Operator
* Laplacian Operator

**Interactive Theory**
For every selected operation, the application provides:
* Definition
* Working principle
* Kernel representation
* Mathematical formula
* Applications
* Advantages
This allows the project to function as both an **image-processing tool and an educational learning platform**.

**Technologies Used**
* HTML5
* CSS3
* JavaScript
* HTML Canvas API

**Purpose**

This project is developed as an **Image and Video Analytics (IVA)** assignment to provide an interactive understanding of spatial-domain image processing and gradient operators.
Instead of displaying only the final processed image, the application visually demonstrates **how individual pixel values and convolution kernels produce the final result**.
